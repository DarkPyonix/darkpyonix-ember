오너 결정(2026-10-25)을 반영한 Ember 에디터(D32)입니다. 다른 화면은 바꾸지 않았습니다.

폭

결정

  • 바탕은 앱 기본 스타일입니다. 둥근 패널(아일랜드), 탭, 도구 창, 코드 영역이 JetBrains의 최신 Islands 디자인 개념과 맞다는 오너 판단입니다.
  • 좌우 도구 창 띠만 JetBrains식 40px 아이콘 띠로 바꿨습니다. 선택된 버튼은 흰 바탕과 그림자 없이 옅은 선택 색만 씁니다.
  • 단축키는 VS Code와 JetBrains 중 고릅니다. 탭 줄의 ⋯ 메뉴 아래 "단축키 체계"에서 바꾸고, 화면의 단축키 표시와 실제로 받는 키가 함께 바뀝니다. macOS는 ⌘, 다른 OS는 Ctrl입니다(?os=other로 미리 봅니다). 선택은 브라우저에 저장됩니다.
  • 브레드크럼은 지금처럼 탭 아래에 둡니다(리더 결정, 오너가 정하지 않음).
